# Epic 1 Context: Platform Foundation & Core Playback Engine

<!-- Compiled from planning artifacts. Edit freely. Regenerate with compile-epic-context if planning docs change. -->

## Goal

Establish the full-stack monorepo foundation for AlgoScope, integrating Next.js 14 App Router, FastAPI backend in Python 3.12 (uv), SQLite persistence via SQLAlchemy 2.0, NextAuth OAuth security, and the core `useAlgorithmPlayback` deterministic timeline state machine with UI controls. This unblocks all downstream algorithmic visualization topics.

## Stories

- Story 1.1: Monorepo Scaffolding & Dual-Stack Environment Setup
- Story 1.2: Owner-Implemented OAuth Authentication & Session Management
- Story 1.3: SQLite Database Models & Topic Seed Scaffolding
- Story 1.4: Frame Schema Contracts & Playback Engine State Machine (`useAlgorithmPlayback`)
- Story 1.5: Dashboard Shell & Assessment Data API

## Requirements & Constraints

- **Monorepo Structure:** Decoupled `frontend/` (Next.js 14 App Router, TypeScript, Tailwind CSS, shadcn/ui) and `backend/` (FastAPI, Python 3.12 managed via `uv`, Pytest).
- **Quality & Strict Types:** Strict TypeScript (`tsc --noEmit`), ESLint + Prettier for frontend, Ruff and Pytest for backend. Zero lint/type errors allowed.
- **Persistence:** Local file-based zero-configuration SQLite database (`algoscope.db`) via SQLAlchemy 2.0.
- **Security:** NextAuth.js OAuth authentication protecting personal learning metrics.
- **Performance:** Local page loads under 2s, 60fps responsive scrubber.

## Technical Decisions

- **AD-1 (Frame Schema Protocol):** All algorithmic visualizations adhere to `Frame(step, phase, state, pointers, highlights, explanation)` with metrics (`comparisons`, `swaps`, `time_complexity`).
- **AD-2 (Deterministic State Machine):** Frontend `useAlgorithmPlayback` hook maintains pure, indexed timeline navigation (`status: idle | playing | paused | stepping | completed`, `currentIndex`, `speedMs`).
- **AD-3 (Dual-Stack Learning Tasks):** Boilerplate and layout generated by AI; owner implements Python algorithms/generators/tests and TypeScript frame adapters/hooks.
- **AD-4 (Monorepo Topology):** Root `package.json` coordinates dev scripts; root `.gitignore` ignores Python venvs, node_modules, `.next`, and SQLite databases.

## UX & Interaction Patterns

- **Topic Hub (Landing):** Grid of 14 topic cards with difficulty ratings and mastery badges.
- **Playback Suite:** Play/Pause, Step Back, Step Forward, Speed Selector (0.5x, 1x, 2x, 5x), timeline range scrubber.
- **Dashboard Shell:** Radar/bar charts comparing pre vs. post assessment scores and active streak counters.

## Cross-Story Dependencies

- Story 1.1 establishes the workspace layout required by all subsequent stories.
- Story 1.2 and 1.3 configure authentication and database models needed for user session state.
- Story 1.4 provides the core playback hook and contracts needed for Epic 2 (Arrays) and Epic 3 (Graphs).
