# Epic 2 Context: Linear Archetype — Topic 1: Arrays & Strings

## Goal

Deliver the complete end-to-end learning lifecycle for Topic 1 (Arrays & Strings), establishing the Linear Archetype reference implementation. This includes diagnostic pre-assessment grilling, educational pattern cards, owner-implemented Python sliding window frame generators with pytest suites, owner-implemented TypeScript linear canvas adapters, a dedicated Traffic Anomaly Monitor rate-limiter mini-app, and post-assessment mastery reflection.

## Stories

- Story 2.1: Topic 1 Diagnostic Grill & Educational Hub
- Story 2.2: Python Sliding Window Algorithm & Frame Yields (Backend)
- Story 2.3: TypeScript Linear Array Canvas Adapter (Frontend)
- Story 2.4: Curated Problems Suite for Arrays & Strings
- Story 2.5: Mini-App: Traffic Anomaly Monitor & Rate-Limiter
- Story 2.6: Post-Assessment Grill & Mastery Reflection

## Requirements & Constraints

- **Dual-Stack Learning Ownership:** Scaffolding generated by AI with guided TODO stubs; learner implements Python algorithms/Pytest suites and TypeScript frame reducers, canvas adapters, and UI triggers.
- **5-View Topic Structure:** Every topic provides 5 structured routes: Overview/Inspiration (`/topics/[slug]`), Interactive Demo (`/topics/[slug]/demo`), Dedicated Mini-App (`/topics/[slug]/project`), Pattern Cheat Sheet (`/topics/[slug]/patterns`), and Curated Problems (`/topics/[slug]/problems`).
- **Deterministic Frame Protocol:** Algorithmic execution yields deterministic `Frame[]` sequences adhering to `Frame(step, phase, state, pointers, highlights, explanation)` powering `useAlgorithmPlayback`.
- **Diagnostic Grill (0-10 scale):** Diagnostic pre-assessment before coding and post-assessment upon completion measuring Conceptual Understanding, Pattern Recognition, and Complexity Analysis accuracy (persisted to SQLite via `POST /api/assessments`).
- **Quality & Strict Types:** Strict TypeScript (`tsc --noEmit`), ESLint, and Python `ruff` / `pytest`. Zero lint/type errors allowed.

## Technical Decisions

- **Archetype Canvas:** Topic 1 uses linear bar layout with Framer Motion pointer cursors and sliding window bounding boxes.
- **Assessment Persistence:** Baseline scores captured via `POST /api/assessments` with `assessment_type: "pre"`, updating topic progress status to `"in_progress"`.
- **Offline First:** All question sets, educational markdown, and pattern cheat sheet data are served locally via FastAPI or Next.js static data.

## UX & Interaction Patterns

- **Pre-Assessment Grill Modal/Card:** 3 interactive diagnostic questions presented on first entry to `/topics/arrays-and-strings` before unlocking coding views.
- **Pattern Cheat Sheet:** High-density, scannable reference cards with visual indicators for sliding window, two pointers, prefix sums, and Kadane's algorithm.
- **Real-World Inspiration:** Overview section illustrating TCP sliding window and packet buffers with clear diagrams.

## Cross-Story Dependencies

- Story 2.1 establishes `/topics/arrays-and-strings` route and diagnostic pre-assessment required to set baseline scores and unlock Story 2.2–2.6.
- Story 2.2 provides the backend Python execution endpoint yielding frames required by the Story 2.3 linear canvas adapter.
- Story 2.6 completes the topic lifecycle, comparing against the baseline pre-assessment established in Story 2.1.
